# WorldArchitect evidence media

This public repository hosts exact-byte copies of visual evidence from the unlisted evidence gists for [PR #9975](https://github.com/jleechanorg/worldarchitect.ai/pull/9975) and [PR #10050](https://github.com/jleechanorg/worldarchitect.ai/pull/10050). It exists only to provide anonymous browser-correct media MIME types for linked GIF/MP4/WebM files. The unlisted gists remain the evidence records and contain the complete manifests and provenance.

`MEDIA_MANIFEST.json` records each source gist raw URL, byte count, and SHA-256. The media files are served through GitHub Pages at `https://jleechanorg.github.io/worldarchitect-evidence-media-20261003/`, which is the URL form to use for inline/downloadable media.
